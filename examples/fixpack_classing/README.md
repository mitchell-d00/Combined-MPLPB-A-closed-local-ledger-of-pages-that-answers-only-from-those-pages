# Fictional dump-to-ledger walkthrough

Last reviewed: 2026-11-18.

Run `bash examples/fixpack_classing/walkthrough.sh` from the repository root. The script creates a fresh temporary dump and ledger, proposes literal drafts, uses explicitly scripted fictional choices, validates the staged build and asks strict/reformulated/unofficial questions. It leaves the temporary directory printed at the end for inspection. “Demo Reviewer” is a fictional fixture name, not an actual independent reviewer. No authentic historical corpus or original benchmark is changed.

The input files are copied from the supplied fixpack. Correction and retirement drafts require explicit acceptance/choices; the fixture script makes those choices visibly. Internal ratification alone does not override unknown-authorship restrictions for external delivery. Recorded outputs and any deliberate differences from the supplied transcript are retained with the new engineering report.
