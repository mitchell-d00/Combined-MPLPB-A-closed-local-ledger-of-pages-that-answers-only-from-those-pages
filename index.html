Double-click Launch_MPLPB.bat on Windows, or run this from the extracted repository:

Keep the terminal running, then open the local interface. A plain HTML file cannot run the Python reader or crawl your folders itself.

How to use

  1. Choose a corpus and delivery profile. The tile map shows its actual records and eligibility.
  2. Open an eligible tile to read its plain text, hash and sealed metadata. Use “Ask about this scope” to query the real reader.
  3. Ask a question. Read the reader outcome separately from the gate’s source cards. Several cards do not establish a relationship between their facts.
  4. Inspect the revision tree for source timestamps, revision IDs and wikitext pins. Stored verification is historical; this view performs no live check.

Your own pages

python3 launch.py --root /path/to/corpus

The journal lasts for this tab only. Visual setting, theme, selected corpus and profile are saved in this browser. Questions and source text are not saved there. Chat turns and declared notes use a local save slot and resume after refresh or app relaunch. Restart explicitly clears that session; imported sources remain. Browser storage holds a session ID, not source text.

Keyboard

E explore · A ask · R revision tree · C chat · J journal · Esc close source. Shortcuts pause while typing.

The rule still matters.

This front end calls MPLPB’s existing lexical reader and provenance gate. It adds no model, semantic search or generated answer. Unknown authorship stays unknown. A source pin proves bytes, not the truth of a claim.
