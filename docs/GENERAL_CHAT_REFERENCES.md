# General chat research notes

The eight topic records in resources/general_chat.json are authored paraphrases checked against NASA and NOAA educational web pages on 2026-10-09. Each record retains its source title and URL. They provide small offline starting points, not a complete encyclopedia. Saved eligible pages are consulted first. Only chat mode uses the note fallback; serious-mode evidence rules are unchanged. Specific questions outside these notes continue through existing handling. Follow-up “tell me more” uses the selected note.

UI help and topic-list commands are explicit procedures. “How do I search?” provides search instructions; “list topics” lists eligible pages in the current scope.
