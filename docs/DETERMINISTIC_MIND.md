# Deterministic mind and browser save slot

Built over main `17896e3`; this branch is not published automatically.

The browser is an actual client of the Python MPLPB reader and gate. It preserves
player-style state through a known local save slot, not a filesystem crawl. Install
or clone the repository, run `python3 launch.py`, and use the local browser URL.

Finite intent rules add declared notes, exact-title source excerpts, comparisons,
historical explanations and typed relationship queries. Same command, pinned
sources and working state produce the same response; event UUIDs and timestamps
are outside that deterministic decision. No model, semantic retrieval, consciousness
or autonomous goal planner is implemented. Ordinary ownership remains lexical.

The ledger is independent of session state. Restart deletes only the selected
session. Profile/corpus changes drop selected-topic context without deleting notes
or transcript. Notes remain user declarations. Source changes force re-selection
before a contextual answer; historical traces are explicitly historical.

The save envelope and turn chain detect inconsistent bytes, not a malicious rewrite.
A corrupted save stops loading and is retained unchanged. Restore a trusted backup;
do not mistake integrity checks for authorship or identity verification.

The uploaded address-opening package has not been applied wholesale. Its language
routing and raw HTML capture deficiencies require a separate verified integration.
Current network commands remain the existing explicit Wikipedia search/import.
