# Deterministic behavior classes

A class identifies a conversational act, not a memorized input sentence. Sentence
forms fill slots in a discourse frame. State and guards select the reaction;
existing response constructors compose the wording. The same input and complete
session state yield the same result. Variation across turns comes from saved
state, not random sampling. This is a finite grammar, not an LLM or unrestricted
language understanding.

| Class | Required state/guard | Allowed reaction | Forbidden reaction |
| --- | --- | --- | --- |
| Social question | Complete wellbeing grammar; unique temporal candidate | Compose social reply | Factual source claim or automatic lookup |
| Temporal correction | Recent social frame | Acknowledge changed slot and reply socially | Reinterpret a source question as a greeting |
| Attribute correction | Recent question and matching page context | Reconstruct question and run normal evidence checks | Answer from chat memory or change the entity |
| Attribute follow-up | Recent question and matching page context | Fill omitted subject; run evidence checks | Reuse stale subject or bypass evidence |
| Missing/stale context | No uniquely eligible frame | Ask to resend full question | Pretend to understand |
| Unsupported grammar | Literal, negation, extra clause, number, unknown entity | Preserve existing handlers | Silently discard restrictive wording |

Only the temporal slot of a full social question tolerates spelling edits. Exact
matches rank 100, spacing variants 95, and one-edit variants 85. Ties abstain.
These are ordinal rule ranks, **not calibrated probabilities**. Factual entities,
values, and source passages are never fuzzy-matched by this layer.

Recent frames persist across reloads and brief courtesies, expire after more than
two intervening turns, and are invalidated by substantive topic/control changes.
Short corrections do not edit the transcript. Every repair records its rule,
ranked candidates, chosen reaction, original input, and referenced turn. Source
follow-ups still validate the selected page, delivery profile, and evidence.

Examples generated by the classes include `Hi how are you to ight` followed by
`Sorry I meant tonight`, and `how big is it?` followed by `and age?`. Other time
words, supported attributes, greetings, and polite forms exercise the same rules.

## Reproduce the data

```sh
python -m unittest discover -s tests -p test_conversation_repairs.py -v
python -m tools.evaluate_conversation_repairs --output /tmp/behavior-results.json
python -m tools.evaluate_context_matrix --output /tmp/context-matrix.json
python -m tools.smoke_conversation_architecture
```

The audit has 240 scenarios across ten fixture topics. Each record includes the
behavior class, expected reaction, actual conversation, interpretation trace,
sources, and transcript-chain check. Coverage includes social variants,
corrections, reloads, courtesies, stale frames, missing facts, damaged pages,
literals, negation and compound questions. It is developer-authored regression
data, not independent validation. A passing scenario is not proof that every
sentence in the corresponding language class is supported.

## Observed results

On the evaluated working tree based on `6a7601b`, all 240 behavior scenarios
passed: 60 social questions, 30 temporal repairs, 20 attribute repairs,
20 attribute follow-ups, 40 clarification cases, 10 compound requests,
10 missing-evidence cases, 10 damaged-source cases, 10 stale-source cases,
and 30 literal/negation/no-reinterpretation cases.

The final full regression suite passed 555 tests. The existing 1,000-response
audit and 250 confirmation calls passed; the personal-context matrix passed
360/360 and the fixed conversation scenarios passed 78/78 turns.
`results.json` contains all scenario conversations, traces, expected results,
source identifiers, chain checks, and evaluated source hashes. There is no claim
of probabilistic confidence, independent validation, or universal language coverage.
