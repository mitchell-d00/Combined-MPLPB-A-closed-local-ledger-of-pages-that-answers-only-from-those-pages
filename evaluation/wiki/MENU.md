# Menu

```
python3 tools/menu.py
python3 tools/menu.py 8
```

The menu lists the combined commands, the open-web clone, the wiki live match, and the five carried parts. Search means asking a folder that already exists. There is no training step. Networked MPLPB is the part under `parts/networked`: a seed can be copied, a node carries seeds, a hub only says where to look. The clone formats alien pages and does not treat co-presence as a relationship.
