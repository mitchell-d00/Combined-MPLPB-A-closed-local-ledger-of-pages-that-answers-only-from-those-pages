# Polybius-Extend projection rule

The original FRUS HTML bytes, source paths, SHA-256 commitments and raw
anchor ranges stay fixed. Select the single publisher document div.
Before passing it to the canonical body reader, collapse runs of ordinary
HTML whitespace in text nodes outside preformatted elements to one
space. Preserve explicit markup, entities, block and line-break elements,
and preformatted text. Layout-only lines from delivery markup therefore
cannot split an otherwise continuous assertion in the experiment.

Use the same frozen questions, source order, controls, reference spans,
and passage and character budgets in both arms. Separate discovery
coverage from supported Strict Ask answers. Accept only if all frozen
anchors still map to the projected source, no control gains false
support, no previously covered pair loses coverage, and at least one
additional pair achieves complete native anchor coverage. This experiment
changes the FRUS projection harness. Strict Ask's proof rules stay fixed.
