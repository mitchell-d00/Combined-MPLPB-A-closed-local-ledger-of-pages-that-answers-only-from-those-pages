# FRUS-Boundary frozen admission and withhold rule

A two-source comparison may be complete when the current Strict Ask
checker uniquely resolves both requested appearances to eligible originals
and independently certifies each requested proposition with an exact
witness under the sealed passage and character budgets. Preserve the
speaker, attributed reporter, document role, and modality of each
proposition. For a request that asks for a causal, implementation, or
temporal link, require a separate exact witness for that link, with
document and event dates distinguished. A request for two attributed
statements can be satisfied by a source-scoped comparison. It requires
no causal link between the statements.

Discovery anchors are scored separately. A retrieved span supplies
neither a typed native proposition nor a completion certificate. If one
requested proposition has a certified proof, retain only its checked
partial. If neither proposition has a certified proof, withhold the
comparison and name the missing certificate. If an asserted outcome or
link in a negative control lacks a witness, withhold it. Do not promote
topical overlap, chronology, retrieved text, or the local reference key
to proof. Preserve the original answerable labels even when the current
checker must abstain.

Test only the four frozen comparisons and their existing four controls.
Use the same publisher-layout projection, eligible sources, source
order, budgets, and keys. Record zero false-supported bridges as an
acceptance invariant. This candidate is an explicit evaluation
boundary for the current checker. It introduces no native proof grammar.
