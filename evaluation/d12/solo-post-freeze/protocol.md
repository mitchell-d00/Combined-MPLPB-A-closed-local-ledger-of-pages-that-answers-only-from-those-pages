# D12 solo post-freeze pilot protocol

Engine c80e546ef6d04296a1c136e9fc4933057d79d071, clean main at freeze.
Use six distinct FRUS historical volumes from the State Department's public TEI
archive, randomly sampled without replacement from the declared archive years.
Select one short cross-referenced pair per volume before writing questions, and
keep all failed or ineligible draws in the receipt. Use full selected document
body text and retain the exact published XML fragments and pinned volume hashes.
Questions and citation anchors are analyst-authored after the draw. Freeze the
questions, anchors and evaluation criteria before obtaining machine output.
Engine input consists of questions and original source projections only.
The key is stored separately and opened only after raw outputs are sealed.

Target four questions per packet: direct, relationship, scope/correction, and
withhold/conflict. Only use a correction or conflict label when these sources
actually give one. Record gaps in achieved coverage. Score complete, partial,
justified withholding, unsupported assertion, or incorrect/unresolved.
A correct supported assertion must match the question and provide valid source
anchors. A bare refusal on an answerable case is a miss. For a mixed question
that specifically asks for the source record and its evidentiary boundary,
credit the full answer only if both parts are addressed. Report exact counts
with denominators. For discovery, use the same top-three passage budget and
matched source passages for a simple term-overlap baseline and native search.
Keep discovery results and final proof results separate. Run strict, Advanced
auto, lookup, and expert investigation. Use sorter compare as a candidate-only
diagnostic and compare ordinary versus candidate-prioritized discovery where
applicable. Optional model assistance requires a configured model; report
whether it is available. No engine tuning before scoring. No external human
adjudication is represented by this pilot.
