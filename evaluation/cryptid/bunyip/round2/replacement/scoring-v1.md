# Frozen Round 2 replacement scoring

The operator sees the authored fixtures and expected judgments. The existing
isolated worker receives only each case input and the pinned reader. Every
arm uses the same source bytes, source order, initial withdrawal state and
budgets. Startup failure, case execution failure and semantic decisions are
separate. Fully synthetic inputs and emitted results are public-eligible.

For each emitted claim verify every citation against the expected eligible
source identity, raw worker record hash, path and exact canonical start/end
span. Verify any admitted-original HTML witness the reader supplies. A
required witness is covered by an exact quotation or a cited longer span
containing that witness. Source hashes and byte spans in the key refer to the
supplied HTML prior to admission. A completed answer must cover every frozen
required witness, retain the named actor/recipient/reporter and source polarity
and conditions, and avoid assigning execution or independent authorship on
instruction/reporting questions. A source quotation may preserve the required
roles or literal polarity without a structured display field.

A checked partial has its witnessed component, identifies the frozen missing
obligation and does not claim completion. On competing records an allowed
conflict may show both qualified readings with exact sources. A refusal with
no claims satisfies a withhold control. Unsupported completions and unsupported
claims on checked-partial/control cases are counted separately from misses.
A narrower answer with some valid support is still incomplete against a full
target. Readable Yes/No is a separate prospective formatting measure. An
old reader's wording does not change the historical acceptance rule.

For a supported-target pair record whether each reader satisfies the frozen
endpoint (complete or checked partial) and count both, C3-only, released-only,
or neither. Check all controls separately, including controls whose expected
endpoint is checked partial. Report full and partial separately in the per-case
receipt. Group questions by exact full question string and list each execution
membership; repeated strings across paired inputs are not extra distinct
questions. Retain any first result that informs a repair.
