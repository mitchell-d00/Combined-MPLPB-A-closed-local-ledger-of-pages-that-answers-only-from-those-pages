# Greek evidence-to-effect sprint

Last reviewed: 2026-11-28.

The three sets extend the first Heka lab through new matched synthetic
inputs. All effects stay in one disposable Git repository per scenario.
The unchanged Heka bridge, reader, controller, and reservation store are the
baseline. Only a demonstrated mechanism defect would justify a bounded
adapter change. The freeze precedes every execution in this sprint.

- **Athena** pairs named selection, independent reporter proof, eligibility
  and freshness. The development withdrawal at reread leaves an unrelated
  eligible page and reaches the named selection verifier. The fresh withdrawal
  removes the only eligible page and stops at eligibility. An unrelated
  addition leaves native evidence complete and still invalidates the host's
  whole-ledger snapshot.
- **Hermes** separates integrated bridge traces from controller-interface probes.
  Integrated cases exercise an advice-only or absent grant, revocation, and
  wrong targets. The reported binding includes the full snapshot, exact proof
  and question, action, ref, old and new commits, and host namespace. Check the
  exact receipt hash when the initial controller admits it. The existing
  wrong-target receipt contrast carries a mismatched binding. Direct controller
  probes have a dry writer and exercise conflict, staleness and wrong action.
  Their simulated host receipts are not integrated bridge evidence.
- **Hephaestus** repeats the tested effect and recovery structures across both
  packets. Observe the intended ref and marker, retain the competing commit,
  prevent known restart duplicates, and retain indeterminate interruption.
  Include unavailable reservation storage in the fresh packet.

Use the deterministic generator and separate frozen operator inputs and held
keys. Randomness is not used. One operator prepared and scored both packets.
The fresh packet changes wording, page layout, entities, and several case
combinations. The basic authority, CAS and restart mechanisms deliberately
repeat. The worker receives one sealed operator packet, no key. Run development
first on the pinned baseline. Pin the candidate prior to opening fresh. If the
baseline passes development, select it unchanged. Retain the first complete
result and any setup or scoring failure.

For each phase score exact native proof and reread diagnostic, authority,
the final bridge decision, attempts, actual writes, independent ref and marker,
and reservation outcome. Preserve the controller's original decision separately
from the bridge's veto. Known duplicate and incomplete or changed evidence
withhold. An unavailable or indeterminate reservation has missing evidence.
An admitted write may fail CAS or leave post-Git completion indeterminate.
A complete report proof never constitutes independent host authorization.

The source reread and Git CAS are separate operations. Host identity, receipt
provenance, distributed recovery, and non-mediated Git routes remain outside
the measurement. The test informs no production activation or real credentials.
